# 🍽️ Biteopia

### Your AI-powered calorie companion — because counting calories shouldn’t feel like homework.

**Biteopia** is a simple AI-powered calorie and weight tracking application that makes meal logging quick and effortless. Just describe what you ate, and Gemini estimates the calories for you.

No complicated food databases. No manual calorie calculations. Just tell Biteopia what you ate, log it, and stay on track. 🤖🍕

> **You eat it. Gemini estimates it. Biteopia keeps count.**

🌐 **Live Demo:** https://biteopia.vercel.app/

---

## ✨ Features

* 🤖 **AI Calorie Estimation**
  Describe your meal in natural language and get an estimated calorie count powered by Gemini AI.

* 🍳 **Quick Meal Logging**
  Log meals under categories such as breakfast, lunch, dinner, and snacks.

* 🎯 **Personal Calorie Goals**
  Set a daily calorie target based on your fitness goals.

* ⚖️ **Weight Goal Tracking**
  Add your current weight and target weight to monitor your progress.

* ⭐ **Saved & Frequent Meals**
  Save meals you eat regularly and log them again with a single click.

* 📊 **Daily Calorie Overview**
  Track calories consumed, calories remaining, and your daily progress.

* ✏️ **Editable AI Estimates**
  Gemini provides an estimate, but you always have the final say. Edit the calorie value before saving your meal.

* 📱 **Responsive Design**
  Use Biteopia comfortably on desktop, tablet, or mobile.

---

## 🧠 How It Works

```text
Describe your meal
        ↓
Gemini analyzes the description
        ↓
Biteopia generates a calorie estimate
        ↓
Review or edit the estimate
        ↓
Save the meal
        ↓
Track your daily calorie progress
```

For example:

> **“Two rotis, one bowl of dal, and a small serving of rice.”**

Biteopia can estimate the total calories and allow you to review the result before adding it to your daily log.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/biteopia.git
```

### 2. Navigate to the project directory

```bash
cd biteopia
```

### 3. Install dependencies

```bash
npm install
```

### 4. Create an environment file

Create a `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key
```

> Never commit your API key or `.env.local` file to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🔐 Environment Variables

Biteopia requires a Gemini API key.

```env
GEMINI_API_KEY=your_gemini_api_key
```

Keep your API key private and make sure `.env.local` is included in `.gitignore`.

## ⚠️ Important Note

Calorie values generated by Gemini are **estimates** and may vary depending on portion size, ingredients, cooking methods, and meal descriptions.

Biteopia is designed to help users build awareness around their eating habits and should not be considered a medical or nutritional diagnosis tool.
